Job Agent

Privacy Policy for Job Agent

Effective date: 2026-11-15.

1. Who this covers

Job Agent ("the App") is a private tool operated by Brian Harper ("the Operator"). The Operator is its only user. The App is not offered to the public. This policy describes what the App does with Google account data.

2. Google permissions the App holds

The App holds 3 permissions on one Google account that the Operator owns ("the Account").

(a) Gmail, read-only. Google grants this permission for the whole mailbox. The App requests only the messages that carry the Gmail label "Job Alerts". It requests no other message.

(b) Gmail, insert. The App places a digest message in the inbox of the Account after each run. This permission cannot read, send, edit or delete mail.

(c) Google Sheets, read-only. Google grants this permission for every sheet the Account can open. The App reads columns A to E of one tab of one sheet. That sheet holds the Operator's own job application log. The App never changes the sheet.

3. What the App keeps and why

3.1 From each job alert email, the App keeps the job title, the company name, the location and the result of the lookup described in this Section. It uses them to find the same job on the employer's public job board. It does not open the links inside alert emails.

3.2 From the sheet, the App reads the company, the role, the application date, the outcome and the outcome date. It uses them to avoid showing the Operator a job he has already applied to, and to mark a job that has been posted again.

4. Storage

4.1 The App runs on GitHub Actions inside a private repository on GitHub ("the Repository"). The Operator is the only user with access to the Repository.

4.2 A copy of each alert email exists on the GitHub Actions machine only while a run is in progress. GitHub discards that machine when the run ends. When the Operator runs the App on his own computer, the copy is saved in a folder on that computer.

4.3 The fields listed in Section 3.1 are stored in the App's database and working files. The database and working files are kept in the Repository and on the Operator's computer.

4.4 The rows read from the sheet are not saved in the Repository. For each job posting, the database holds a mark that says whether the Operator applied to that job, or to that company, before.

4.5 Each run saves its output, including the digest, in the Repository for 14 days. The digest may show the date of an earlier application beside a job that has been posted again. A weekly backup of the database is kept in the Repository for 35 days.

4.6 The sign-in token that Google issues to the App is stored as an encrypted secret in the Repository and in a settings file on the Operator's computer.

5. Sharing

5.1 The App does not sell, rent or share Google data. It does not use Google data for advertising. No person other than the Operator reads it.

5.2 The App does not send the text of any email, or any content of the sheet, to a third party. It sends company names to public employer job boards to look up open roles. Some of those company names come from alert emails.

5.3 Other than the storage described in Section 4 and the lookups described in Section 5.2, the App transfers no Google data to any third party.

5.4 The App uses an AI model from Anthropic to compare public job descriptions with the Operator's own profile. The text sent to the model is the public job posting and that profile. It contains no email content and no sheet content. The App does not use Google data to create, train or improve any artificial intelligence or machine learning model.

6. Limited Use

The use of information received from Google Workspace scopes will adhere to the Google User Data Policy, including the Limited Use requirements. That policy is published at https://developers.google.com/terms/api-services-user-data-policy.

7. Retention and deletion

7.1 The Operator can delete the stored data at any time by deleting the App's database, its working files and the saved run output.

7.2 The Operator can also revoke the App's access to the Account at any time at https://myaccount.google.com/permissions.

8. Changes

A change to this policy will be posted on this page with a new effective date.
